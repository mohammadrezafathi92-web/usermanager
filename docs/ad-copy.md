# متن‌های آماده‌ی تبلیغات کانال

هر متن را در بخش **تبلیغات ← تبلیغ جدید** کپی کن. کدهای داخل `{}` موقع ارسال
با داده‌ی زنده پر می‌شوند، پس دست‌کاری‌شان نکن:

| کد | چه چیزی جایش می‌آید |
|---|---|
| `{package}` | نام پکیج |
| `{quota}` | حجم پکیج |
| `{days}` | مدت به روز |
| `{price}` | قیمت با جداکننده |
| `{code}` | کد تخفیف |
| `{code_expires}` | تاریخ انقضای کد (شمسی) |
| `{bot}` | آیدی ربات |

**قبل از استفاده:** متن‌هایی که کد تخفیف دارند فقط وقتی درست کار می‌کنند که در
همان تبلیغ یک کد تخفیف انتخاب کرده باشی، وگرنه به‌جای کد یک خط تیره می‌آید.

---

## ۱ — معرفی ساده (همیشه کار می‌کند)

```
🚀 پکیج {package}

📦 {quota}
⏳ {days} روز
💰 {price} تومان

تحویل آنی و خودکار، بدون معطلی.
سفارش: {bot}
```

## ۲ — تأکید روی چند پروتکل

```
⚡️ یک اشتراک، شش پروتکل

WireGuard · OpenVPN · V2Ray · L2TP · IKEv2 · SSTP
هر کدام جواب نداد، سراغ بعدی برو — بدون خرید دوباره.

📦 {package} — {quota} / {days} روز
💰 {price} تومان

{bot}
```

## ۳ — کد تخفیف با مهلت

```
🎁 کد تخفیف فعال شد

کد: {code}
⏰ فقط تا {code_expires}

روی پکیج {package} ({quota} · {days} روز)
قیمت پایه: {price} تومان

کد را موقع خرید در ربات وارد کن 👇
{bot}
```

## ۴ — چند دستگاه هم‌زمان

```
📱💻 روی گوشی، لپ‌تاپ و تبلت — هم‌زمان

با یک اشتراک {package} همه‌ی دستگاه‌هایت وصل می‌شوند.

📦 {quota} | ⏳ {days} روز | 💰 {price} تومان

{bot}
```

## ۵ — تمدید (برای مشتری‌های قدیمی)

```
🔄 تمدید بدون دردسر

یوزر و پسوردت همان می‌ماند.
کانفیگ جدید نمی‌گیری، چیزی را دوباره تنظیم نمی‌کنی —
فقط حجم و زمانت تازه می‌شود.

{package} · {quota} · {days} روز · {price} تومان
{bot}
```

## ۶ — پشتیبانی

```
🛟 پشتیبانی واقعی، نه ربات جواب‌های آماده

سؤالی داشتی، مشکلی پیش آمد — همین‌جا در ربات بپرس.

📦 {package} — {quota} / {days} روز

{bot}
```

## ۷ — شروع سریع

```

۱. وارد ربات شو
۲. پکیج {package} را انتخاب کن

{quota} · {days} روز · {price} تومان
{bot}
```

## ۸ — مقایسه‌ی قیمت روزانه

{bot}

## چند نکته که فروش را بیشتر می‌کند

**تنوع را حفظ کن.** ۵ تا ۸ تبلیغ فعال بگذار، نه یکی. چون به‌صورت چرخشی ارسال
می‌شوند، کانال تکراری نمی‌شود و اعضا حساسیت پیدا نمی‌کنند.

**فاصله را کم نگذار.** هر ۶ تا ۱۲ ساعت کافی است. تبلیغ زیاد باعث سکوت کردن
(mute) کانال می‌شود و آن‌وقت هیچ‌کدام دیده نمی‌شوند.

**«حذف تبلیغ قبلی» را روشن بگذار** اگر کانالت محتوای دیگری هم دارد، تا کانال
به دیوار تبلیغات تبدیل نشود.

**کد تخفیف با مهلت واقعی بگذار.** اگر کد همیشه فعال باشد، فوریتش را از دست
می‌دهد و دیگر کسی عجله نمی‌کند.

**عکس اضافه کن.** پست‌های تصویردار در تلگرام محسوس‌تر دیده می‌شوند. یک بنر
ساده با نام برند و قیمت کافی است.

**ادعای اثبات‌نشدنی نکن.** «هیچ‌وقت قطع نمی‌شود» یا «۱۰۰٪ تضمینی» اولین باری
که خلافش پیش بیاید اعتماد را می‌برد — و در این کار حتماً پیش می‌آید. متن‌های
بالا عمداً روی چیزهایی تمرکز دارند که واقعاً داری: چند پروتکل، چند دستگاه،
تحویل آنی، گزارش مصرف، و تمدید بدون تغییر کانفیگ.
