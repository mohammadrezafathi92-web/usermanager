# متن‌های آماده‌ی تبلیغات

۲۴ متن برای بخش **تبلیغات** پنل. همه‌شان مینی‌اپ و تست رایگان را می‌گویند،
و عمداً از هم دور نگه داشته شده‌اند — لحن، طول، و زاویه‌ی ورودشان فرق می‌کند
تا کانالت مثل یک ربات که یک جمله را تکرار می‌کند به نظر نرسد.

## قبل از استفاده

**جایگزین‌ها** (پنل خودش پرشان می‌کند، دست‌کاری‌شان نکن):

| جایگزین | چه می‌شود |
|---|---|
| `{package}` | نام پکیج |
| `{quota}` | حجم، مثلاً «۵۰ گیگابایت» |
| `{days}` | مدت به روز |
| `{price}` | قیمت با جداکننده |
| `{code}` | کد تخفیف |
| `{code_expires}` | تاریخ انقضای کد (شمسی) |
| `{bot}` | آیدی ربات |

هر متنی که `{package}` یا `{price}` دارد، موقع ساختن تبلیغ باید یک پکیج
انتخاب کنی؛ وگرنه پنل به‌جایش خط تیره می‌گذارد. متن‌هایی که جایگزین ندارند
هر جا و همیشه قابل استفاده‌اند.

**متن دکمه** را هم می‌توانی عوض کنی — پیش‌فرضش «🛒 خرید و اطلاعات بیشتر»
است. برای تبلیغ‌های تستی «🎁 دریافت تست رایگان» بهتر جواب می‌دهد.

**ترتیب:** به هر کدام یک «ترتیب» متفاوت بده تا چرخش منظم باشد.

## دسته‌ی ۱ — تست رایگان، خط مقدم

### ۱

```
🎁 اول امتحان کن، بعد پول بده.

تست رایگان ما نه شماره کارت می‌خواهد، نه پیش‌پرداخت، نه ثبت‌نام طولانی.
وارد {bot} شو، فروشگاه را باز کن، روی «دریافت رایگان» بزن.

سرویست همان لحظه ساخته می‌شود.
```

### ۲

```
⚡️ سی ثانیه تا اولین اتصال

۱. {bot} را باز کن
۲. دکمه‌ی «فروشگاه» پایین صفحه
۳. «دریافت رایگان»

تمام. نه فرم، نه انتظار، نه تماس با پشتیبانی.
```

### ۳

```
چرا تست رایگان می‌دهیم؟

چون می‌دانیم بعد از امتحان کردن برمی‌گردی.
سرعت و پایداری‌مان را از حرفِ ما نپذیر — خودت ببین.

🎁 تست رایگان در فروشگاه ربات: {bot}
```

### ۴

```
🎁 تست رایگان، بدون هیچ شرطی

بدون کارت بانکی. بدون شماره موبایل. بدون «اول شارژ کن».
یک دکمه در مینی‌اپ، و سرویس در دستت.

{bot}
```

### ۵

```
تست رایگان ما محدود است — نه برای اینکه شما را عجول کنیم،
بلکه چون ظرفیت روزانه دارد و واقعاً تمام می‌شود.

اگر امروز می‌بینی‌اش، یعنی هنوز جا هست. 🎁

{bot}
```

## دسته‌ی ۲ — مینی‌اپ، خط مقدم

### ۶

```
📱 فروشگاه ما داخل خود تلگرام است.

نه سایت، نه لینک پرداخت مشکوک، نه اپلیکیشن جداگانه.
همان تلگرامی که باز است: {bot} → فروشگاه

پلن‌ها، کیف پول، سرویس‌های فعال، تمدید — همه یک‌جا.
```

### ۷

```
دیگر لازم نیست با ربات چت کنی.

مینی‌اپ ما یک فروشگاه واقعی است: پلن‌ها را کنار هم می‌بینی،
مقایسه می‌کنی، یکی را می‌زنی، تمام.

🛍 {bot}
```

### ۸

```
📱 هر چیزی که لازم داری، در یک صفحه:

• پلن‌های فعال و قیمتشان
• حجم باقی‌مانده و تاریخ انقضای سرویست
• کیف پول و افزایش اعتبار
• 🎁 تست رایگان

فروشگاه را از {bot} باز کن.
```

### ۹

```
سه تا سؤالی که همیشه می‌پرسید، حالا خودت جوابش را می‌بینی:

«چقدر حجمم مانده؟»  «کی تمام می‌شود؟»  «چطور تمدید کنم؟»

📱 فروشگاه → سرویس‌های من. همین.

{bot}
```

### ۱۰

```
🛍 فروشگاه جدید ما بالا آمد.

طراحی تازه، پلن‌ها دسته‌بندی‌شده، خرید با دو تپ.
و برای کسانی که هنوز مشتری ما نیستند — 🎁 تست رایگان بالای صفحه.

{bot}
```

## دسته‌ی ۳ — پکیج‌محور (پکیج انتخاب کن)

### ۱۱

```
📦 {package}

{quota} — {days} روز
💰 {price} تومان

خرید با دو تپ در فروشگاه {bot}
و اگر هنوز مطمئن نیستی، 🎁 تست رایگان همان بالاست.
```

### ۱۲

```
{package} | {quota} | {days} روز

قیمت: {price} تومان

بدون واسطه، بدون انتظار — مستقیم از فروشگاه داخل تلگرام.
🎁 تست رایگان هم داریم، اول آن را بگیر.

{bot}
```

### ۱۳

```
💡 حساب ساده:

{quota} برای {days} روز = {price} تومان

اگر ماهی چند بار قطعی اینترنت کارَت را عقب می‌اندازد،
این عدد از یک بار عقب افتادن کمتر است.

📱 {bot} → فروشگاه
```

### ۱۴

```
📦 {package} دوباره موجود شد.

{quota} · {days} روز · {price} تومان

فروشگاه: {bot}
اول تست رایگان، بعد تصمیم. 🎁
```

## دسته‌ی ۶ — با زاویه‌ی متفاوت

### ۲۱

```
یک سؤال صادقانه:

چند بار سرویس خریدی که روز سوم قطع شد و پشتیبانی جواب نداد؟

ما به‌جای قول دادن، تست رایگان می‌دهیم. 🎁
امتحان کن، اگر خوب بود بمان.

📱 {bot}
```

### ۲۲

```
🎁 برای کسانی که هنوز از ما نخریده‌اند

تست رایگان فقط یک‌بار و فقط برای مشتری جدید است.
اگر قبلاً از ما خرید کرده‌ای، این پیام برای دوستت است — برایش بفرست.

📱 {bot}
```

### ۲۳

```
👥 دوستت را دعوت کن، هر دو سود می‌کنید.

کد دعوتت را از فروشگاه بردار: {bot} → فروشگاه
او تخفیف می‌گیرد، تو اعتبار.

🎁 و اگر تازه‌وارد است، اول تست رایگان را بگیرد.
```

### ۲۴

```
📱 فروشگاه باز است، همین الان.

پلن‌ها دسته‌بندی شده‌اند: تک‌کاربره، خانوادگی، و مخصوص روزهای سخت.
هر کدام را بزنی، مشخصاتش را می‌بینی.

🎁 تست رایگان هم بالای صفحه است.

{bot}
```

## چند نکته‌ی عملی

**تعداد در چرخش:** با ۲۴ متن، اگر روزی دو تا بفرستی، دوازده روز طول
می‌کشد تا یکی تکرار شود. اگر کمتر می‌فرستی، نصفشان را نگه دار برای ماه بعد
— تازگی خودش ارزش دارد.

**عکس:** به هر تبلیغ یک تصویر بده. پست‌های تصویردار در کانال تلگرام
به‌مراتب بیشتر دیده می‌شوند. لازم نیست حرفه‌ای باشد؛ یک اسکرین‌شات تمیز از
خودِ مینی‌اپ از هر بنر استوکی بهتر جواب می‌دهد، چون همان چیزی را نشان
می‌دهد که طرف قرار است ببیند.

**متن دکمه:** برای تبلیغ‌های دسته‌ی ۱ «🎁 دریافت تست رایگان» بگذار، برای
بقیه همان «🛒 خرید و اطلاعات بیشتر».

**یک هشدار:** متن شماره ۵ می‌گوید ظرفیت روزانه دارد — این را فقط وقتی
بفرست که واقعاً سقف روزانه‌ی تست را تنظیم کرده باشی. ادعای کمیابی‌ای که
پشتش چیزی نیست، اولین باری که کسی امتحان می‌کند و می‌بیند همیشه در دسترس
است، به اعتبارت می‌خورد.
